# Icepak 真实数据 · 服务器训练部署包

用你生成的 10 组 Icepak 真实仿真报告，在 GPU 服务器上一键训练并对比 3 个模型：

| 编号 | 模型 | 内容 |
|------|------|------|
| 1 | baseline | 论文原版算法（纯功率输入） |
| 2 | 3d5 | 改造算法（功率+掩码+界面三通道 / 分区k PDE / 界面热流连续） |
| 3 | 3d5-ni | 消融：3d5 但关闭界面热流连续 |

数据：10 个样本 → 8 训练 + 2 测试，网格 101×101×56。
结果目录：`DeepOHeat-v1/results/results_volume/DeepOHeat_v1/tag_*/`

---

## 一、上传

把这个 **`icepak_data_out` 文件夹整体** 上传到 GPU 服务器。位置放在 **DeepOHeat-v1 旁边** 即可（也可放在里面），脚本会自动向上查找代码目录。

```
服务器上建议结构：
    /root/autodl-tmp/
        ├── DeepOHeat-v1/          （原有代码，含 models.py / heat_volumetric.py）
        └── icepak_data_out/       （本部署包，整个文件夹传上去）
```

## 二、运行

```bash
cd /root/autodl-tmp/icepak_data_out
bash deploy_icepak_train.sh
```

脚本会自动完成：
1. 定位代码目录、检查 10 个报告是否齐全
2. 把 `icepak_samples.txt` 里的路径自动替换成服务器路径
3. 备份原有 data/（备份到 `data_backup_orig_时间戳/`）
4. 调用 `make_icepak_dataset.py` 生成真实数据集（8 训练 + 2 测试）
5. 依次训练 baseline → 3d5 → 3d5 无界面（batch=8，默认 3000 轮）
6. 打印三组对比摘要（loss 末段 / rel_l2 / MAPE）

## 三、选配参数（默认即可）

```bash
# 只训练 500 轮（快速看效果）
EPOCHS=500 bash deploy_icepak_train.sh
```

## 四、看结果

训练完后脚本会自动打印三组 `rel_l2_mean / mape_mean` 对比。

详细曲线与数据在：

```
DeepOHeat-v1/results/results_volume/DeepOHeat_v1/
    tag_baseline_mode/              原版
    tag_mode_3d5_full/              改造
    tag_mode_3d5_no_interface/      消融
```

每个目录里有：
- `log (loss).csv` —— 训练 loss 曲线
- `log (eval metrics).csv` —— rel_l2 / rmse / max_l1 / mape / pape
- `train_console.log` —— 完整训练日志
- `DeepOHeat_v1_trained_model.eqx` —— 保存的模型

改造有效 = 3d5 的 `rel_l2` / `MAPE` 明显低于 baseline（且不高于基线太多时训练 loss 也能收敛）。
